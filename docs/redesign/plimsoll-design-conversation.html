R3決定

沒 DB 存本地、有 DB 就把本地資料灌入

你要

沒連線就存本地化；連上 DB 後要能把本地資料存進 DB。

決定／產出
  • local-first ＋ DB 可選上游；DB 永遠是下游鏡像。
  • 關鍵：append-only 事件日誌（每筆 event_id）＝免衝突同步協定，同步只是 idempotent 往前補。
  • §23 SyncTarget 契約；三態 tag（本機／未同步／已同步）由 sync_state.json 推導。

R4決定

防竄改＋啟動不受 DB 影響＋介面顯示連線

你要（連續補充）

讀檔時整份 hash 快照存別處、灌 DB 前比對，不一致告警並略過；DB 不能影響程式啟動；設定裡要看得到有沒有連上 DB（新前端工作）。

決定／產出
  • 凍結前綴 hash 錨點（相容 append-only 的合法成長）；不一致 → 告警＋略過＋隔離待人工。
  • §24：啟動只讀本機、DB 延遲背景探測、失敗降級本機、永不阻塞。
  • ui-spec §3.4 加「資料庫同步」狀態區（綠/灰燈、待同步數、手動同步、完整性告警）。

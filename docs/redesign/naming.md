# 產品命名提案

## 主推：**Plimsoll**

**中文：載重線**　｜　定位標語：*船舶技術文件版本差異 Agent*

Plimsoll line（載重線／滿載吃水線）是船身上那條法定標記——**船可以裝多重、吃水可以到哪裡，越過就違法、就危險**。19 世紀由 Samuel Plimsoll 推動立法，是海事史上第一個把「安全界限」變成強制標示的制度，至今全球每艘船的船舷上都有。

為什麼適合這個產品：

| 產品核心 | Plimsoll 的呼應 |
|---|---|
| 標出技術文件中的安全門檻變更（85 °C → 80 °C） | 載重線就是「不可越過的界限」 |
| 強制人工覆核才能簽核放行 | 載重線是法定強制標示，不是建議 |
| 主要使用者是船舶維修／輪機／驗船人員 | 這行沒有人不認得 Plimsoll mark |
| 需要一個好記、專業、不土的名字 | 兩個音節、拼寫獨特、可直接當 domain 與 CLI 名 |

視覺延伸：載重線標記本身（⊕ 圓中一橫，兩側刻度）是現成的 logo — 極簡、幾何、黑白，正好吻合這次的視覺方向。圓中橫線也可以直接當「版本分界線」的隱喻。

命名用法：
- 產品名：`Plimsoll`
- 全稱：`Plimsoll — 船舶技術文件版本差異 Agent`
- 套件／repo：`plimsoll`

## 備選

| 名稱 | 意涵 | 優點 | 缺點 |
|---|---|---|---|
| **Driftwatch** | 監看「版本漂移」，drift 在海上即漂流 | 功能直白、英文語感好 | 偏工具感，少了工安權威性 |
| **Sextant** | 六分儀，靠精準測量定位 | 呼應「100% 精準頁碼定位」 | 與「版本差異」關聯較間接 |
| **Tideline** | 潮線，兩個狀態之間的分界 | 意象美、好記 | 太柔和，缺少「安全強制」的重量 |
| **Freeboard** | 乾舷，甲板到水面的安全高度 | 同樣是海事安全術語 | 比 Plimsoll 冷門 |

# DEMO Ship Document Comparison

這是一個以船舶文件比對為主題的研究與概念驗證專案，目標是整理基層船員實際可能使用的比對流程、常見風險，以及相關產品的商業模式。

## 文件

- [船上基層人員的文件比對流程與常見風險](docs/ship-document-comparison-workflow.md)
- [文件比對公司的傳統與常見獲利模式](docs/document-comparison-business-models.md)

## 目前涵蓋範圍

- 船上文件版本、有效性與欄位核對；
- 證書、貨物、工作許可、工時及污染紀錄；
- 文件與現場狀態的交叉確認；
- 不符合事項的回報與更正原則；
- 文件比對軟體、人工服務及海事合規產品的收費方式；
- 可套用到船舶文件比對產品的初步商業假設。

## 使用提醒

本專案內容供研究、需求分析及產品設計參考，不能取代船旗國、港口國、船級社、公司安全管理系統（SMS）或船長與合格船員的正式判斷。

研究頁面均盡量附上官方或第一手來源；涉及價格或產品方案的資料可能調整，引用時應重新確認來源頁面。
